# `osgi-itest/src/test/java/hu/blackbelt/judo/meta/keycloak/osgi/itest` — Pax Exam integration tests booting Karaf and asserting model bundle publication

| File | Purpose |
|---|---|
| `KarafFeatureProvider.java` | Assembles the Pax Exam Karaf container options shared by every ITest here. Exports `karafConfig(Class)`, `configureVmOptions()`, `karafUrl()`, `getFreePort()`, `getKarafPort()`, `getOsgiService(...)` overloads, `findBundleByName`, `assertBundleStarted`, `waitWebPage`, `sleepOrTimeout`, `testTargetDir`, `explode`, constants `KARAF_VERSION = "4.3.3"` and `SERVICE_TIMEOUT = 30000`. `karafConfig` resolves features from `target/test-classes/test-features.xml`, so the resource must be copied before the container starts; it replaces `etc/org.ops4j.pax.url.mvn.cfg` only when `-DuseCustomSettings=true`, and opens a JDWP socket on 5005 only when `-DisDebugEnabled=true`. `getOsgiService` never closes its `ServiceTracker` and throws `RuntimeException` after the timeout instead of returning null. |
| `KeycloakModelLoadITest.java` | Proves a `Keycloak-Models` bundle becomes an injectable `KeycloakModel` service inside a real Karaf. `@RunWith(PaxExam)` with `@ExamReactorStrategy(PerClass)`; exports `config()`, `getProvisonModelBundle()`, tests `testEvlModelValidation()` and `testZetaModelValidation()`. `config()` provisions `hu.blackbelt.judo.meta.keycloak.osgi` plus a TinyBundles bundle built at run time whose `Keycloak-Models` header points at `model/northwind-keycloak-keycloak.model`; the model is empty, so both tests expect a clean validation. The header `name` must stay `northwind-keycloak`, otherwise `@Inject KeycloakModel` never resolves and the container times out. |
