# `model-test/src/test/java/hu/blackbelt/judo/meta/keycloak/runtime` — JUnit 5 suites covering model building, JSON export, and EVL/Java validation parity

| File | Purpose |
|---|---|
| `KeycloakConfigurationExporterTest.java` | Exercises realm-to-JSON export on a two-client `sandbox` realm (one confidential, one public). Exports `testConfigurationExporter()`, calling `getConfigurationAsString()` then `writeConfigurationToFile(File)`. Writes to `target/test-classes/sample-keycloak-realm.json`; asserts nothing, so it only guards against exceptions, not output shape. |
| `KeycloakExecutionContextTest.java` | Placeholder for builder-pattern model creation; `testKeycloakReflectiveCreated()` only builds a `KeycloakModelResourceSupport` on `urn:keycloak.judo-meta-keycloak` and stops at a `// Build model here` comment. Passes vacuously — do not read a green run here as coverage of the execution context. |
| `KeycloakUtilsTest.java` | Verifies content added via `keycloakModel.addContent(...)` becomes reachable through the resource-support streams. Exports `setup()` (builds `TestKeycloakModel` plus `KeycloakUtils` over its `ResourceSet`), `testClientCreate()` asserting `getStreamOfKeycloakClient()` yields `clientId`, and helper `saveKeycloakModel(String)` writing `target/test-classes/<name>-keycloak.xml`. |
| `KeycloakValidationPerformanceTest.java` | Benchmarks EVL against Java validation (sequential and parallel) on a synthetic model of 10 realms × 100 clients × 100 users. `@EnabledIfSystemProperty("performance.test"="true")` — skipped unless that property is set. Sizes override via `perf.realms`/`perf.clients`/`perf.users`/`perf.iterations`. Asserts ≥10000 elements and `javaSeqAvg <= evlAvg * 1.5`, so it fails when Java validation regresses relative to EVL. |
| `KeycloakValidationTest.java` | Constraint suite for realm, client, user, credential, and attribute-binding rules; every case is `@ParameterizedTest` over `@EnumSource(ValidatorType.class)`, so each rule must behave identically in EVL and Java. Expectations use `KeycloakValidationConstants` names; `CLIENT_NAME_NOT_EMPTY` and `USER_EMAIL_VALID_FORMAT` are asserted as warnings, the rest as errors. |
