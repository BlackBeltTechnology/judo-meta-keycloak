# `model/src/main/java/hu/blackbelt/judo/meta/keycloak/runtime` — hand-written runtime services: EVL execution, JSON binding, model traversal

| File | Purpose |
|---|---|
| `KeycloakEpsilonValidator.java` | Runs the EVL rule set against a loaded `KeycloakModel`. Exports three `validateKeycloak(...)` overloads (script-root only; plus expected errors/warnings; plus `useCache`) and `calculateKeycloakValidationScriptURI()`. Registers the model under EVL name `Keycloak`, injects `keycloakUtils`, and always resolves `keycloak.evl` relative to `scriptRoot`. Executes with `parallel(true)`; commits and closes the context in `finally`, swallowing close failures. URI calculation branches on plain directory, `.jar`, and `jar:bundle:` code sources, so it works both in a JAR and inside Karaf. |
| `KeycloakObjectMapper.java` | Supplies the shared Jackson binding that can read Keycloak realm JSON back into EMF objects. Exports static `objectMapper()` over an immutable singleton, plus public `ClientImplWithCollectionSetters`, `UserImplWithCollectionSetters`, `RealmImplWithCollectionSetters` and `ClientSkipAttributeBindingsMixIn`. MixIns route each interface to an `*Impl` subclass exposing collection setters; `EListDeserializer` fills `BasicEList` from JSON arrays via the contextual element type. Unknown properties are ignored (`FAIL_ON_UNKNOWN_PROPERTIES=false`), so typos in input JSON pass silently. Private constructor — never instantiate. |
| `KeycloakUtils.java` | Gives EVL scripts and runtime code typed traversal over a whole `ResourceSet`. Exports `KeycloakUtils(ResourceSet)` and `all(Class<T>)`; `all()` and `asStream(Iterator, boolean)` are package-private. `all(Class)` always walks serially and filters by `isAssignableFrom`, so it returns implementation instances of the requested interface. Constructor eagerly builds a `KeycloakModelResourceSupport` on the given set; the EVL plugin script relies on this constructor's signature. |
