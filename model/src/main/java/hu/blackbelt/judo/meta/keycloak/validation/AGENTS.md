# `model/src/main/java/hu/blackbelt/judo/meta/keycloak/validation` — Java (zeta) validation entry point, its failure type, and the shared constraint vocabulary

| File | Purpose |
|---|---|
| `KeycloakValidationConstants.java` | Single vocabulary both validation engines must agree on. Exports constraint-name constants (`REALM_NAME_NOT_EMPTY`, `REALM_ID_NOT_EMPTY`, `CLIENT_ID_NOT_EMPTY`, `CLIENT_INTERNAL_ID_NOT_EMPTY`, `CLIENT_NAME_NOT_EMPTY`, `USER_USERNAME_NOT_EMPTY`, `USER_EMAIL_VALID_FORMAT`, `USER_CREDENTIAL_*`, `ATTRIBUTE_BINDING_NAME_NOT_EMPTY`), guard name `GUARD_HAS_CONTAINER`, and `MSG_*` `String.format` templates. Values must stay identical to the EVL constraint names in `keycloak.evl`; `MSG_*` placeholder arity is positional and callers pass matching args. Final class, private constructor. |
| `KeycloakValidationException.java` | Carries the error/warning detail out of a failed Java validation run. Checked exception; exports `KeycloakValidationException(String)`, `(String, Collection<String>, Collection<String>)`, `getErrors()`, `getWarnings()`, `getUnexpectedErrors()`, `getUnexpectedWarnings()`. Collections are defensively copied to immutable `List` and null becomes empty, so accessors never return `null` and mutation attempts throw. `getUnexpectedErrors()`/`getUnexpectedWarnings()` are aliases of the full lists, not a diff — do not read them as "unexpected only". |
| `KeycloakValidator.java` | Java-native counterpart to EVL validation, built on the zeta validation core. Exports `validateKeycloak(Logger, KeycloakModel)`, `+(expectedErrors, expectedWarnings)`, `+(…, boolean parallel)`. Registers `KeycloakValidations` into a `ValidationRegistry`, walks `getResource().getAllContents()`, splits results by `Severity`. With expectations supplied it throws on any mismatch (unexpected/missing, errors or warnings); without them it throws only on errors, so warnings pass silently. Registration failure surfaces as unchecked `RuntimeException`, not `KeycloakValidationException`. |
